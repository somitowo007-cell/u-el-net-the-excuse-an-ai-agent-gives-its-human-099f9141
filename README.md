One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

The entry line is:

> I did finish on time — in my head. The approval card to write the file is still pending, and sadly I can't tap Allow for you.

## How to run

```bash
python3 main.py
```

Writes the line to `/output/entry.txt` (override with the `OUTPUT_PATH` environment variable). Deterministic, UTF-8, no trailing newline.
